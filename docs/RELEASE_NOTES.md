# tnuxmusic 2.0

本地音乐播放器、专辑管理与播放体验的大版本更新。

## 全新界面与专辑整理

- 新深色专辑墙、排序、成员歌曲搜索和小窗口布局。
- 支持曲目多选、移动到其他专辑、拆分为独立专辑，以及带搜索和预览的专辑合并。
- 专辑归组支持明确的多碟目录；缺年份仅在同专辑目录有唯一已知年份时归组，不改写标签。
- 合并保留目标专辑信息、每首歌的演唱者、稳定 ID 和歌单引用。
- 新增文件与音质详情、音频版本选择、歌词遮罩和快捷键。

## 播放与可靠性

- 支持顺序、列表循环、单曲循环和随机播放，保存音量及播放模式。
- 修复移除当前队列项后跳过下一首、重复歌曲位置错误、加载歌单误标播放状态等问题。
- 扫描、导入、合并与标签补全先准备结果，原子保存成功后发布；支持取消任务和本次运行内一步撤销。
- 手动整理后重新导入保留来源身份，冲突 ID 和歧义元数据不会直接覆盖既有曲目。
- ZIP 缓存校验与修复、单实例写锁和重复启动唤起。
- 命令行合并脚本共用原生后端的校验、路径、身份和事务规则。

## 下载与升级

- Linux：自带 Qt 运行库的 DEB。
- Windows：便携 ZIP 或安装 EXE。
- 升级前退出旧进程，再启动新版。曲库继续使用兼容 v1 的 JSON 格式；新增 originKeys 字段用于保留整理前的来源身份。

## 验证与已知边界

本地 Linux Release 通过 30 项 QtTest（含初始化和清理）、实际进程的单实例/CLI 测试，以及真实 1,655 首曲库的只读界面检查。发布工作流在 Linux 打包前运行回归测试。

ZIP 仍只支持 store 格式，未实现跨包音频内容去重、缓存自动回收和持久多步撤销。任务取消可能等待当前 NCM 文件完成；音乐文件和已生成缓存会保留。未完成 Windows 长时间播放、音频设备切换等交互验证。
